# Hey, I'm Benjamin 👋

I'm building [ClimbSync](https://climbsync.app) full time, from Vienna.

ClimbSync is an app for climbing with friends. You see when your friends are heading to the gym or the crag, plan sessions together, and find new places to climb. I wanted it to exist for years, so I finally built it.

## What it does

- **Sessions.** Say when and where you're climbing and see who's joining.
- **Plans.** Find a time that works for the whole group, without the group chat back and forth.
- **Gym map.** Discover climbing gyms nearby, with opening hours and details.
- **Keytags.** Your gym cards on your phone, even offline.
- **Friends.** Add the people you climb with, and keep control over who sees what.

Available in English, German, Spanish, French, Italian and Chinese.

## How it's built

It's a one-person, bootstrapped project with no investors. The code lives in a private repo.

| | |
|---|---|
| App | React Native, Expo, TypeScript |
| Backend | Convex |
| Data and UI | TanStack Query, React Native Paper, Reanimated |
| Maps | Mapbox |
| Payments and analytics | RevenueCat, PostHog |
| Website and docs | Astro, Mintlify |
